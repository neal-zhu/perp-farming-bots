# Perp Hedge Kit

独立、开源、自托管的跨交易所永续对冲工具，面向会使用交易所和钱包、但不会编程的用户。

**当前状态：设计阶段。此仓库尚无可运行的交易程序。**

用户在自己的机器或服务器运行程序，通过浏览器连接账户、选择两个交易所和币种、设置价差条件与金额、创建多个对冲仓位，并主动关闭仓位。程序展示实际成交、费用、资金费、盈亏、各平台积分与告警。

## 独立实现

本项目不复制、导入或移植任何私人交易项目的代码、测试、配置、数据样本或内部文档。实现来源为本仓库的独立规格、公开上游依赖及官方协议资料。未确认的交易、费用、积分与订单状态必须保持明确未知。

## 推荐技术栈

- Python 3.12、asyncio：后台执行与账户连接。
- NiceGUI / FastAPI：浏览器界面与本地接口，一个运行进程。
- SQLAlchemy / Alembic / SQLite：交易操作、成交分配和重启恢复。
- Lighter 官方 Python SDK：优先接入 Lighter Robinhood 与 Core。
- CCXT / CCXT Pro：经过验收的其他交易所连接。
- Arcus：单独开发永续 adapter；已找到的官方 spot SDK 不承担永续下单。
- Docker Compose：单容器自托管发行；依赖固定版本和哈希。

以上是选型，不表示已安装依赖、已实现连接或通过实盘验收。

V1 的默认模式为用户指令驱动。无自动止损、止盈、保证金补充、ADL 后对侧交易或重复刷量循环。用户发起的建仓失败补偿、明确授权的关闭与原订单恢复属于执行过程。

积分必须依据各平台规则和可靠读取来源展示。对冲不等于积分资格；官方不披露的积分不能由成交量猜测。

自托管仍需要常驻运行设备。关闭浏览器不影响后台；关闭程序或服务器会停止条件监测，交易所上的仓位仍然存在。
