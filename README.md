# Perp Farming Bots

独立、开源、自托管的永续交易策略工具，面向会使用交易所和钱包、但不会编程的用户。内置策略逐步涵盖跨交易所对冲、网格和剥头皮等 perp farming bots。

**当前状态：设计阶段。此仓库尚无可运行的交易程序。**

用户在自己的机器或服务器运行程序，通过浏览器连接账户、选择策略、填写少量参数并启动 bot。可以同时运行多个 bot，查看各自订单、持仓、成交、费用、资金费、盈亏和告警；各平台积分按账户展示。

对冲是第一版策略。网格和剥头皮属于后续内置策略，当前没有实现。产品名称、bot 生命周期、执行和账本不限定为双腿对冲。

| 内置策略 | 用户主要参数 | 计划状态 |
| --- | --- | --- |
| 跨交易所对冲 | 两个账户、币种、价差条件、金额 | 首版 |
| 永续网格 | 一个账户、币种、方向、价格区间、网格数量、预算 | 后续 |
| 剥头皮 | 账户、币种、明确入场/出场规则、单次金额、预算 | 后续；具体规则待定义 |

## 独立实现

本项目不复制、导入或移植任何私人交易项目的代码、测试、配置、数据样本或内部文档。实现来源为本仓库的独立规格、公开上游依赖及官方协议资料。未确认的交易、费用、积分与订单状态必须保持明确未知。

## 推荐技术栈

- Python 3.12、asyncio：后台执行与账户连接。
- NiceGUI / FastAPI：浏览器界面与本地接口，一个运行进程。
- SQLAlchemy / Alembic / SQLite：交易操作、成交分配和重启恢复。
- Lighter 官方 Python SDK：优先接入 Lighter Robinhood 与 Core。
- CCXT / CCXT Pro：经过验收的其他交易所连接。
- Arcus：单独开发永续 adapter；已找到的官方 spot SDK 不承担永续下单。
- Docker Compose：单容器自托管发行；依赖固定版本和哈希。

以上是选型，不表示已安装依赖、已实现连接或通过实盘验收。

每个 bot 只执行用户选择策略中明确展示的规则。首版对冲无自动止损、止盈、保证金补充、ADL 后对侧交易或重复刷量循环。后续网格的挂单/补单、剥头皮的策略出场属于用户授权的策略规则；公共运行模块不自行引入额外风险交易。建仓失败补偿、明确授权的关闭与原订单恢复属于执行过程。

暂停停止新策略动作，已接受操作仍需确认和恢复。停止可以撤销该 bot 的挂单，但不自动清仓；“停止并平仓”是独立明确操作。持仓有多个 bot 共用时，关闭只处理所选 bot 的已分配数量。

积分必须依据各平台规则和可靠读取来源展示。farming 是产品使用场景，不保证任何策略获得积分；官方不披露的积分不能由成交量猜测。

自托管仍需要常驻运行设备。关闭浏览器不影响后台；关闭程序或服务器会停止条件监测，交易所上的仓位仍然存在。
