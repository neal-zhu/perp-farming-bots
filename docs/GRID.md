# 永续网格使用规则

第一版为单账户、价格触发的等差永续网格，支持 Arcus、Lighter Core、Lighter Robinhood 的 BTC / ETH / SOL。后台约每 3 秒检查；到达相邻格线后通过现有真实签名路径提交限价 IOC。程序需要在线，订单不会提前挂在交易所。

## 参数与预算

选择账户实例、方向、价格下限/上限、2–100 格、最大名义仓位预算和滑点。中性模式需要偶数格。预算不是保证金，程序不设置杠杆、不自动补保证金。可用抵押资产须覆盖预算，保存配置不下单。

填写后直接点击“保存 Bot”，无需单独预览或检查。保存新网格、修改未启动网格的参数时，自动查询原生市场规则和账户余额，核对每格最小数量/金额、预算、外部仓位与委托，以及账户/币种占用。检查期间按钮显示“检查并保存…”，防止重复提交。失败不保存，在保存按钮上方显示具体的最低预算或余额差额，保留已填参数。运行时仍重新检查。已建立网格仅修改名称或滑点，不重新要求空闲余额覆盖已分配的整份预算。

最低每格数量 = max(数量精度、交易所最小数量、最小金额 / 实际下限)，按数量精度向上取整；最低网格预算 = 最低每格数量 × 实际上限 × 最大份数。最低预算提示向上取到美分，避免显示金额仍低于实际门槛。余额读取失败会阻止保存，不会当作零或沿用旧值。

切换币种会清空旧区间，必须重新填写或点击“填入当前价 ±10%”。更改参数会清除上次错误提示；旧行情请求迟到时不能覆盖新币种或手动修改的区间。保存不会建立仓位，运行后若价格在区间外则等待进入。

生成 N+1 条格线，按交易所价格精度取整。做多/做空最多 N 份数量，中性最多 N/2 份。每份数量 = 预算 / 实际上限 / 最大份数，再按数量精度向下取整；最大名义仓位不超过预算。每份数量在整个区间须符合最小数量和最小金额，否则明确拒绝。

## 初始仓位和买卖

运行后首次进入区间时，选择离当前盘口中价最近的格线作为游标 k，从零仓位建立初始目标仓位。每份数量记为 q：

| 方向 | 游标 k 的目标净仓位 | 向下到下一格 | 向上到上一格 |
| --- | --- | --- | --- |
| 做多 | (N−k)q | 买入增加多仓 | reduce-only 卖出减多仓 |
| 做空 | −kq | reduce-only 买入减空仓 | 卖出增加空仓 |
| 中性 | (N/2−k)q | 加多仓或减空仓 | 减多仓或加空仓 |

例如区间 58,000–62,000、4 格、中性模式，60,000 为零仓位。59,000 买入一份多仓，回到 60,000 减仓卖出；61,000 卖出一份空仓，回到 60,000 减仓买入。同一账户同时只持有一个方向；经过零仓位确认后才可反向开仓。

用可成交买价/卖价判断格线，不使用中价穿越来冒充成交。下单前再次检查行情和区间，网格买入限价不高于触发格线、卖出限价不低于触发格线。跳过多格时每次检查最多处理一格；实际成交数量、价格与手续费决定账目，不补造离线期间的成交。

## 暂停、平仓和恢复

- 超出区间时保留当前仓位、不提交新策略订单；回到区间后继续检查。没有止损、追踪止损或强制减仓。
- 暂停保留仓位和游标；运行恢复原格线。平仓仅 reduce-only 关闭此 Bot 的已分配数量并结束网格。
- 部分成交、结果未知、账户外部仓位/委托变化都停止新动作并显示告警。查询原订单，不重新发送或自动补足未成交数量。
- 完整的迟到成交可推进原游标，但同步后保持暂停，用户点击运行才继续。未达到目标的部分成交保留实际数量，用户可平仓处理；平仓部分成交可再次关闭剩余数量。
- 健康网格重启保留已保存的格线、每格数量和游标；未完成的操作先查询原身份，不能重复初始化。

网格独占账户实例的这个币种。不可与另一网格、对冲 Bot 或手动持仓共用，其他币种不受影响。已有网格状态后锁定账户、方向、区间、格数和预算；名称与已确认状态下的滑点可修改。调整格线请平仓后新建 Bot。

Bot 卡片展示自己的净仓位、均价、价格盈亏、已确认手续费、资金费率预估和全部实际累计成交额。累计金额包含初始仓位、逐格成交及手动平仓。未知手续费保留待确认；实际资金费仍未计入完整盈亏。积分继续按账户采集，不分摊到 Bot。

网格订单墙按价格从高到低展示已经初始化的实际格线：红色为卖出、绿色为买入，标明每次数量及开仓/减仓。蓝色当前价格线按盘口中价定位，当前基准格线单独标记；下一格突出显示，其余标为后续格线。这里是程序内等待触发的策略计划，不是交易所挂单，也不是历史成交。买入距离按可成交卖价、卖出距离按可成交买价计算。

运行面板展示为什么正在等待、下一格触发价格及距离、已确认仓位和成交笔数。中性网格处在中间格时会说明空仓原因。暂停、结束、区间外、行情过期及原订单待确认都有独立提示；行情不可用不沿用旧价格计算距离。未初始化的配置不冒充已经生成原生格线。页面定时更新已有元素，保留展开状态和未保存表单。
